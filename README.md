# ⚡ Світло Миколаїв | Графіки відключень (PWA)

Мобільний PWA-додаток (Progressive Web Application) для зручного перегляду графіків погодинних відключень (ГПВ) та аварійних відключень (ГАВ/СГАВ) АТ «Миколаївобленерго» на базі даних сайту [off.energy.mk.ua](https://off.energy.mk.ua/).

Працює як на смартфонах (Android, iOS), так і на комп'ютерах. Доступний офлайн-режим.

---

## 🚀 Основні можливості

- **Офлайн-робота (Offline-first)**: завдяки Service Worker та збереженню в LocalStorage останні завантажені графіки доступні навіть за повної відсутності зв'язку.
- **Встановлення як додаток**: встановлюється на головний екран смартфона або робочий стіл ПК як нативний додаток без адресного рядка браузера.
- **Швидкий моніторинг**:
  - Відображення поточної ситуації для обраної черги («Є світло», «Відключено», «Можливе»).
  - Таймер зворотного відліку до наступного перемикання (наприклад: *«Вимкнення о 15:00 (через 1 год 12 хв)»*).
  - 48-сегментна компактна шкала поточної доби.
- **Зручний розклад**:
  - Адаптований під мобільні екрани режим карток (без потреби горизонтальної прокрутки 12 колонок).
  - Класичний повнорозмірний табличний вигляд для ПК.
  - Фільтрація за чергами (показ тільки своєї або обраних черг).
- **Пошук за адресою**: інтерактивний вибір філії, населеного пункту, вулиці та будинку для швидкого збереження своєї черги.
- **Легкість і швидкість**: написаний на чистому Vanilla JavaScript та CSS3 без важких фреймворків.

---

## 🛠 Локальний запуск

Для локального тестування з автоматичним проксі API використовується скрипт `server.py`:

```bash
python server.py
```

Після запуску відкрийте в браузері: [http://localhost:8080](http://localhost:8080)
